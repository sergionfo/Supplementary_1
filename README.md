# Supplementary 1
This is the repository for the supplementary material for the paper entitled:  
**Application of the SEISBENCH framework to detect P and S waves of volcano-tectonic seismic sequences: a test using data from the Azores catalogue** \
\
In the **data** folder is the dataset of Santa Barbara. In the future the traces will be added.\
In the **source** folder is the python code used.
